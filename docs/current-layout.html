chaptertools — current layout

A brief of the window as it is, for a layout redesign. Screenshots are the live Tkinter app (clam theme, 11 pt) on a finished book, Startide Rising, unless a caption says otherwise.

The job of the window is one audiobook at a time: measure its silences, pick the published chapter list, place each chapter on a silence, fix the ones that landed wrong, write the chapters into a copy of the file, then put that copy into the library.

Window shell

The window is a horizontal split. The left pane is the library. The right pane is the book. A status strip sits under both.

Stage marks: ✓ done, ● the stage you are on, ! needs attention, ○ not run, ✕ blocked because an earlier stage is not done. Selecting a book jumps to the first stage that is not done.

Measure

Run measure decodes the file once: loudness envelope, timeline check, noise calibration, and the silence list. The result line under the button is the only feedback in the panel. If the MP3 header timing is wrong, a Copy fix command button appears with an ffmpeg command. Measure is what Identify and Align read. A tag edit that does not change the file size does not require it again.

Identify

Source is a radio: ASIN, JSON file, Embedded, or NFO. The text field and Identify check that source against the silences. Browse… is only for a JSON file.

The ASIN source also has a search block. Title and Author start from the MP3 tags, then the last search, then the folder names. Keywords, if filled, replace title and author. Region is an Audible catalog. Search fills the table: ASIN, Title, Author, Narrator, Runtime, Score. Title, Author, and Narrator share extra width. Clicking a row puts that ASIN in the field above.

Under the search, one line says whether the chosen edition fits (chapter count, fit score, rate spread, runtime ratio).

Align

Align places every published chapter on a real silence. Minimum confidence (default 0.5) is the cutoff; chapters under it stay in the table but are withheld from Emit and tinted amber. Near is an optional CH=TIME hint, for example 12=3:45:00. The result line reports how many were placed, the reading rate, and how far the file’s length sits from the published length.

Resolve

This is the tallest panel. On a narrow window the two boxes stack; on a wide window they sit side by side.

The summary line is the unresolved count, or “nothing unresolved.” next: names the cheapest useful action.

Automatic is a ladder. Each row is a label, an optional field, a button, a cost, and a status.

  • Position hint — CH=TIME, then Align with hint. Free. Not a pin.
  • Listen — transcribes about 13 seconds after candidate gaps and pins the announcements it hears. About four minutes.
  • Sweep range — start and end times. Reads that span and pins announced chapters.
  • Sweep probe — ten minutes from the quarter point, to learn whether chapters are announced at all.
  • Full sweep — the whole book. Already-swept spans are cached.

Pin by ear follows the chapter selected in the table. Transport is −10 s, −5 s, Play, +5 s, +10 s, Stop playback, and a playback clock. Under that: a time field, Set from playback, Play from time, Pin, and Remove pin. Playback does not stop by itself.

Emit

Six fields are written into the file as ID3 tags: title, author, album, year, genre, comment. They start from the MP3 tags, then album.nfo, then the folder names. After a successful Identify they are replaced by the edition that was used. Re-read loads the file and folder again. A muted line under the fields lists what was found.

Embed chapters (on by default) also writes a chaptered copy of the audio for Finalize. Off writes only chapters.txt and chapters.json. Emit writes the chapters that are placed and above the confidence cutoff.

Finalize

Dry run prints what would change and writes nothing. Apply then moves the original aside, puts the chaptered file in its place, writes album.nfo, and reloads Audiobookshelf. The checkbox allows a delete-and-re-add of the library entry, which clears listening progress. It is off.

Chapters tab

The table in the screenshots above is this tab. It is the default tab and stays up under every stage except when another tab is chosen.

Columns: #, Title, Published, Placed, Gap, Conf, Pin. Title takes the spare width. A row can be tinted grey (no placement, and the number shows as ?N because it will not be written), amber (under the confidence cutoff, withheld from Emit), or red (a pin that conflicts; the Pin cell reads ! pin). The footer is the color key, the ?N note, and the keys: Space play/pause, arrows ±5 s, Shift+arrows ±10 s, Enter pin, Delete remove pin. Double-click plays from that chapter. Selecting a row fills Resolve’s pin-by-ear title and the sweep range.

The tab label is Chapters N/M: placed count over published count.

Gaps tab

A timeline of the file. Purple bars are pinned chapters, drawn as tall as the silence they sit on. Blue bars are the silences most like those pins. The radio switches the likeness: chapter cadence (where the pin spacing predicts the next chapter) or silence length. The caption counts both and says hover for detail. Times mark the start, middle, and end.

Transcripts tab

A regex filter (case insensitive; empty shows everything) and Show transcripts. The text is what Listen and Sweep heard, each line starting with a time. Double-click seeks playback to that time. The filter also applies to lines already saved on the book.

Log tab

Read-only, selectable, monospace. Save log…, Clear log, and Copy all sit at the top right. A right-click menu copies the selection or everything. The same text’s last line is the status strip. Button clicks anywhere in the window are also written here. The tab title gains an error count when a command fails.

Quality tab

Audio cleanup, separate from chapter placement. Three rows inside the tab.

Analysis. File name, duration, sample rate, channels, and Scan file. The waveform is the whole file: black level, orange clipping, a band where the noise floor jumps. Click-drag selects a span and sets the preview start. Four tiles: integrated loudness against the target, true peak (warning style when it is over 0 dBTP), noise floor, dynamic range. An advice line can offer Turn it on for per-segment denoise.

Chain and detail, side by side. The chain is a preset menu (applied as soon as you pick it), Save as…, a menu for restore / rename / delete, then ten stages in order. Each row is an index, a name, a one-line summary, a modified dot, and an Enabled check. The detail pane is the selected stage: a description, Enabled, Reset to preset, and that stage’s knobs. High-pass is one cutoff. Denoise is spectral or neural, plus strength. EQ is four bands in a two-by-two grid. A stage whose model is missing explains that and does not pretend to run.

Footer. Play, Stop, a start time, “for 30 s”, and Hear original (the preview bypass). Output is MP3 at a bitrate. Process full file writes a cleaned MP3 in the work folder; while it runs the button becomes Cancel. Replace library file swaps it into the library only after a confirm, and keeps the first original.

What a redesign has to keep working

  • Two different selections: the stage strip picks the command panel; the notebook picks the evidence. They are independent, except Quality, which hides the command panel.
  • The chapter table is the shared object. Align, Resolve, and Emit all read the same rows, colors, and pins.
  • Nothing in the panels should assume a tall monitor. Resolve is already the panel that wraps. Identify’s search table and Quality’s detail pane are the other tall regions.
  • Playback, Cancel job, and the log are global. They are not owned by one tab.
  • Quality must not be visually folded into “another pipeline stage.” It does not block Measure through Finalize, and those stages do not block it.
